# LinkedIn project media — DopeKit checklist

Use this when editing your **DopeKit** project on LinkedIn  
(Profile → Add profile section → **Projects** → your project → **Add media**)

---

## 1. Images (upload up to ~10 screenshots)

Pick from `docs/screenshots/` on your machine:

| File | Use for | Why |
|------|---------|-----|
| `landing-home.png` | **Cover / first image** | Best hero shot — brand + booking CTAs |
| `services-pricing.png` | Second image | Shows product depth (menu + gallery) |
| `nearby-map.png` | Third image | Maps + geo discovery |
| `login-auth.png` | Fourth image | Auth + multi-role (client & staff) |

**Skip for now:** `discover-salons.png` (may show API error if backend was down when captured).

**Tip:** LinkedIn crops to ~1.91:1 for the card. `landing-home.png` and `services-pricing.png` work best as the **first** upload.

---

## 2. Links (Add a link)

| Label | URL |
|-------|-----|
| Source code | `https://github.com/2wicem/Nails-service` |
| Live demo | Your deployed URL *(Render / dopekit.co.ke — only if it is live)* |

If no public demo yet, use **GitHub only** — that is still strong for recruiters.

---

## 3. Document (PDF upload)

1. Open `docs/DopeKit-LinkedIn-Brief.md` in Word, Google Docs, or Notion  
2. Export as **PDF** (1 page)  
3. Upload to LinkedIn as **Document**

Or: paste the brief into Canva → use a clean “Project case study” template → Download PDF.

Suggested filename: `DopeKit-Project-Brief.pdf`

---

## 4. Presentation (optional)

If LinkedIn or a portfolio asks for slides, use **5 slides**:

1. **Title** — DopeKit + one-line tagline + your name  
2. **Problem** — WhatsApp booking pain (3 bullets)  
3. **Solution** — Screenshot collage + 4 user roles  
4. **Architecture** — React → Django → PostgreSQL diagram  
5. **Tech & links** — stack list + GitHub QR/link  

Export from Google Slides or PowerPoint as PDF and upload, or share as Google Slides link.

---

## 5. Recommended upload order on LinkedIn

1. Link → GitHub repo  
2. Image → `landing-home.png`  
3. Image → `services-pricing.png`  
4. Image → `nearby-map.png`  
5. Document → `DopeKit-Project-Brief.pdf` (after you create it)  
6. Link → live site *(when deployed)*
